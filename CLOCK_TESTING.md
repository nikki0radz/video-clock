# Clock inbox and Family & Friends test

Open the GitHub-hosted clock and refresh once after this update. It uses the matching interface assets and API from Jonathan’s hosted clock service; each browser keeps its own clock connection and display settings.

In Settings:

- Open **Inbox & sent replies**. Choose an item for a large view and use **Send reply**. The **Sent** tab keeps your replies.
- Set **Maximum artwork hours** (default: two). This limits time on the display; it does not delete the inbox copy. Existing nightly clearing still applies.
- Open **Family & Friends link** and copy the link. That portal can send messages, stickers, photos and postcards, add calendar events, and view the carer schedule. It cannot read the care notes or existing calendar, edit the schedule, or manage the gallery.

A sender reads replies using **Replies from Jonathan** in their named portal. Replies remain private to that sender’s saved browser profile. Older sends without a saved sender profile remain readable but cannot be replied to automatically.

For an independent test, use a fresh browser profile and create a new clock link. Do not reconnect Jonathan’s existing tablet connection merely to test: reconnecting transfers the active tablet connection.

The GitHub page loads the current service assets rather than a stale, separate copy of the clock. Native Android permissions/code are unchanged. Physical-device display, overnight timing and input still need testing.
